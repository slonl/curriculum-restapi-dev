# Source: single-object audit trail

## Source kind

Maintainer conversation on 2026-10-14.

## Expressed direction

After SimplyStore 0.12.0 was released with queryable object history, the
maintainer asked to update the embedded `curriculum-store`, but explicitly did
not want dependency pinning to be a standalone cycle. When offered broader
history-cycle options, the maintainer selected a specific audit trail:

> "lets make it a specific audit trail for a single object - list the full
> history for that specific object."

The maintainer then proposed including a small UI reached from the existing
object view and accepted the bounded form: a history link, a read-only audit
view, and no diffing, restoring, editing, complete historical dataset switch,
or general command browser.

## Scope corrections

The separate dirty standalone checkout at
`/home/auke/git/slonl/spiral/curriculum-store` is explicitly excluded. Work is
limited to the `curriculum-store` and `curriculum-rest-api` submodules inside
`curriculum-restapi-dev`, plus their parent gitlink pins.

Frontend IndexedDB work and broader frontend modernization are being handled
separately and must not be absorbed into this cycle.
