# Cycle: Semantic Continuity Feasibility

## Analyze

Project state / prior evaluation that makes this cycle relevant:

Cycle 1 has been accepted into `curriculum-store` `spiral-development`. The
project has no confirmed governing multi-cycle roadmap yet. Known future work
includes maintainer-workspace and frontend cleanup directions, but this cycle is
a research probe that may determine whether semantic-continuity assistance
deserves roadmap status.

Nearest important risk / uncertainty / desired movement:

The project does not know whether AI-assisted semantic continuity mapping can
make durable-reference maintenance across independently evolved dataset versions
practically feasible.

Relevant human direction / feedback:

The maintainer requested a neutral feasibility cycle and explicitly warned not
to assume AI is appropriate or to modify production maintenance architecture.

## Plan

### Cycle Goal

Produce decision-quality evidence about whether AI-assisted semantic continuity
mapping between independently evolved SLO curriculum dataset versions is
trustworthy and cheap enough to deserve first-class maintainer-workspace roadmap
status.

### Branch Check

Active branch at cycle opening: `spiral/CYC-002-semantic-continuity-feasibility`.

This matches active cycle `CYC-002`.

### Why Now

Durable third-party references are an important project value, but historical
continuity mapping was often too expensive. If AI can reduce that cost safely,
it could change the maintainer workspace roadmap. If it cannot, the project
should avoid investing in a misleading capability.

### Governing Plan / Current Position

No durable governing multi-cycle roadmap is confirmed yet. This cycle is a
research input to possible roadmap formation.

### Plan Continuity Decision

No governing plan. The cycle is compatible with project context because it
investigates a data-maintenance capability without changing production
architecture.

### Current Starting Evidence

- `SRC-002` records the maintainer's feasibility question and constraints.
- `UND-002` records the accepted interpretation and current gap.
- `REQ-002` defines the research request.
- `SRC-003` identifies FO (`slonl/curriculum-fo`) and leerdoelenkaarten
  (`slonl/curriculum-leerdoelenkaarten`) as the candidate latest/earlier
  dataset pair, with shared context repositories.
- `DES-002` defines the smallest useful read-only probe shape for comparing a
  bounded semantic slice before any AI-assisted mapping work.
- `curriculum-store` contains versioned dataset snapshots and history, including
  tags `v2025.2` and `2026.6`, but the cycle has not yet selected a
  representative comparison pair.

### Evaluation Basis

The cycle will be judged by whether it produces a clear, evidence-grounded
positive, negative, or conditional recommendation, including:

- selected dataset/version sample and why it is representative enough;
- mapping procedure and prompts/tools used where material;
- examples of proposed continuity links and non-links;
- auditability of the evidence behind suggestions;
- characterization of splits, merges, moves, renames, broadened/narrowed scope,
  and redistributed parents where present;
- maintainer-facing estimate of review effort and residual risk;
- explicit limitations caused by lack of ground truth.

### Likely Work

- Identify candidate dataset versions/materials for comparison.
- Extract a small but representative sample of entities and context.
- Define a continuity-mapping rubric and output schema.
- Run AI-assisted mapping on the sample.
- Critique and audit the mappings using available names, descriptions,
  hierarchy, references, and consistency checks.
- Produce a feasibility report with recommendation and conditions.

### Explicit Non-Goals

- No production data mutation.
- No `replacedBy` production migration.
- No Open Data maintenance architecture changes.
- No maintainer-workspace feature implementation.
- No complete whole-dataset mapping requirement.

### Pause / Re-Plan Conditions

- No meaningful comparable sample can be identified from available data.
- The available data lacks enough semantic context for responsible mapping.
- The experiment requires production architecture changes.
- AI outputs appear plausible but cannot be audited with available evidence.

### Cycle-Sizing Rationale

This cycle is sized around the feasibility decision. It is larger than a single
probe because the decision requires sample selection, mapping, audit, and
recommendation evidence. It is still bounded: it stops before production
integration or whole-dataset migration.
