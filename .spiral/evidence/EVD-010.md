# Verification Evidence: Enhanced FO Continuity Review Queue

## Claim Being Verified

The Cycle 3 probe can be enhanced into a useful read-only review queue that
combines text similarity, graph context, existing link clues, and bounded Git
timing.

## Why This Evidence Exists

The maintainer asked to enhance the bounded non-exact probe with graph context,
Git timing, and related ranking/explanation inputs.

## Commands Run

Fast deterministic focused run:

```sh
node .spiral/tools/fo-continuity-review-queue.mjs \
  --no-git \
  --types fo_doelzin,fo_subdomein \
  --exclude-generic \
  --limit 12 \
  --min-score 0.25
```

Focused Git-timing run:

```sh
node .spiral/tools/fo-continuity-review-queue.mjs \
  --types fo_doelzin,fo_subdomein \
  --exclude-generic \
  --limit 12 \
  --min-score 0.25 \
  --history-rows 12
```

## Result

The enhanced focused queue reported:

- `7` active Nederlands roots and `19` deprecated Nederlands roots;
- `1,705` active rows and `1,698` deprecated rows in the bounded family;
- `15` missing old rows after filtering to `fo_doelzin` and `fo_subdomein`
  and excluding generic rows;
- `13` candidates at the `0.25` threshold.

The focused no-Git run completed in about one second. The focused Git run
completed after roughly forty seconds, confirming that Git timing is useful but
should remain bounded.

## What Improved

Compared with `EVD-009`, the queue now:

- shows graph context for old and candidate entities;
- penalizes likely programme/level mismatches;
- exposes close alternatives instead of presenting a single overconfident
  answer;
- incorporates existing `replaces` evidence as a small clue;
- adds Git timing as a bounded enrichment rather than a full-dataset cost;
- can suppress generic child rows for higher-signal review.

## Remaining Limits

The scoring is deterministic and heuristic, not calibrated. Scores are ranking
and explanation aids, not probabilities.

Git timing remains relatively expensive because it uses `git log -S`; the
script therefore enriches only a configurable top slice. A production version
would likely need cached history metadata.

The queue still does not decide accepted continuity. It prepares candidates for
human review.

## Evidence Quality

This is useful cycle evidence for the enhanced review-queue direction. It is
not acceptance evidence for production data mutation.
