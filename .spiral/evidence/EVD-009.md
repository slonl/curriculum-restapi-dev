# Verification Evidence: Bounded Non-Exact Nederlands Matching Probe

## Claim Being Verified

Within a limited Nederlands subset, relaxing exact text matching can improve the
candidate review queue for deprecated FO entities without `replacedBy`.

## Why This Evidence Exists

Cycle 3's first report (`EVD-008`) found useful exact-match candidates but did
not test renamed, slightly edited, narrowed, broadened, or reparented
successors. The maintainer asked whether a bounded non-exact pass would improve
the result without reopening the whole dataset.

## Result

Relaxing exact text matching does improve recall inside a bounded Nederlands
set: it surfaces plausible typo cleanup, title/prefix changes, and wording
changes that exact title/description matching would miss.

The cost is a sharp increase in ambiguity:

- havo alone has no missing predecessor descendants, so it cannot answer this
  question by itself;
- the wider Nederlands set has enough missing rows, but contains multiple
  programme variants and repeated active concepts;
- lexical scoring without graph context can choose the right concept in the
  wrong set or level;
- Git timing is helpful but weaker than in `EVD-008`: sampled non-exact old
  rows are typically touched in `267a221` (`2025-09-10`), while candidates
  appear in `01d9b88` (`2025-12-02`) or later, not the same commit.

## Failure Cases / Limits

This was still a simple lexical scorer, not a true semantic model. It does not
understand split/merge relations, hierarchy semantics, or level applicability.

The probe did not validate all `94` missing Nederlands rows manually. It
inspected a focused non-exact subset, mostly `fo_doelzin` and `fo_subdomein`.

No production data changes are justified by this evidence alone.

## Evidence Quality

This is useful evaluation evidence for the review-assistance direction. It
shows that non-exact bounded matching is worth exploring, but only if the next
implementation treats graph context, programme/level, and candidate ambiguity
as first-class ranking/explanation inputs.
