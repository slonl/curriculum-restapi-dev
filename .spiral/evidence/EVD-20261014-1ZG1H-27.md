# SimplyEdit bound-parent compatibility verification

Observed on 2026-10-14 for parent correction commit `8f1d6db`, which pins
curriculum-rest-api `922384d` on
`spiral/CYC-20261014-1ZG1H-22-object-audit-trail`.

## Evaluation finding and cause

After the history route began selecting the correct action, the maintainer's
browser reported `can't access property "$historyHref", shadowValue is null`
from SimplyEdit 1.29 `databind.js`. The history action cleared
`browser.view.item` to `null` before switching templates.

The effective SimplyEdit source preserves child bindings when a bound parent is
replaced. It recognizes `null` as JavaScript type `object`, then iterates the
preserved child bindings and reads each property from the null shadow value.
Adding the nested `item.$historyHref` binding therefore made the existing null
transition fail before the history request could complete.

The orphan action used the identical null assignment. It is covered by the same
correction because the new nested item binding makes that transition vulnerable
for the same reason.

## Correction and verification

REST child commit `922384dc574026ce6151a4c8cb2d2eafc5a96aec` clears the bound
item parent to `{}` in both history and orphan transitions. This preserves the
intended removal of the previous object while giving SimplyEdit an object onto
which it can transfer nested bindings.

`npx tap --disable-coverage test/history.mjs test/command-polling.mjs
test/orphans.mjs` passed all 119 assertions. The history and orphan fixtures now
assert that the cleared bound parent remains object-shaped. The history route,
rendering, stale-response, command-polling and orphan behaviors remain green.

`npm run lint` and `docker compose config --quiet` passed. The complete REST
suite reports 124 passing and the same three failures in the unchanged
`test/changes.mjs` baseline. The staged parent tree passed Spiral RDF validation
with 54 Turtle files, 443 triples and no errors before the parent correction
commit.

## Limits

No controllable browser session was available for a post-correction visual
