# Object history browser-route verification

Observed on 2026-10-14 for parent correction commit `fd8e33c`, which pins
curriculum-rest-api `8d02533` on
`spiral/CYC-20261014-1ZG1H-22-object-audit-trail`.

## Evaluation finding and cause

The maintainer observed that the `Geschiedenis` link changed the location to
`/uuid/:id/history/` but left the normal object view visible. SimplyView 2.1.1
compiles route patterns as start-anchored, non-end-anchored regular expressions
and selects the first matching route in declaration order. The browser declared
`/uuid/:id` before `/uuid/:id/history/`, so the generic route matched the
history location first and invoked the ordinary object action.

The earlier browser test called the history action directly and therefore did
not exercise route selection. This is a cycle implementation and verification
gap, so it is corrected inside the current cycle.

## API boundary check

The running local REST API was queried with its authenticated JSONTag client
contract for one current dataset object. `/uuid/:id` returned an
`application/json` object of 128,006 bytes. `/uuid/:id/history` returned an
`application/jsontag` array beginning with version 0 of 126,692 bytes. Their
SHA-256 hashes differed. This establishes that the dedicated REST handler and
store query were effective; the observed duplicate object view came from the
browser route collision.

An ordinary browser navigation accepts HTML, for which the server deliberately
returns the same application shell at both paths. The client router is
responsible for selecting the history view after that shell loads.

## Correction and verification

REST child commit `8d02533633abcaeddf69871dcd3df02453ba62b3` registers the specific
history route before the generic UUID route. Its regression reproduces
SimplyView's effective prefix and declaration-order matching semantics and
asserts that `/uuid/root/history/` selects `/uuid/:id/history/`.

`npx tap --disable-coverage test/history.mjs test/command-polling.mjs
test/orphans.mjs` passed all 117 assertions. `npm run lint` and
`docker compose config --quiet` passed. The full REST suite reports 122 passing
and the same three failures in the unchanged `test/changes.mjs` baseline; the
new route assertion is green. The staged parent tree passed Spiral RDF
validation with 53 Turtle files, 435 triples and no errors before the parent
correction commit.
