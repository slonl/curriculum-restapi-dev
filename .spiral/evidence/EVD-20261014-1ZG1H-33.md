## Root-cause verification

Before correction, the unrestricted default suite ran 127 assertions: 124
passed and three failed in `test/changes.mjs`. The failures followed from two
2024 test cases passing fixture arrays to `new Changes(array)`. Production
commit `5bb928b` replaced constructor hydration with append-only log restoration
in 2025. Current production call sites create an empty/restored history and
append hydrated `Change` objects; none uses the old array form.

The correction changes only `test/changes.mjs`. Both cases now create an empty
history and append `new Change(item)` values. Their substantive assertions were
not weakened: the collection must contain three entries, and merging two
changes must produce `object1` whose title transition ends at `A new title`.
